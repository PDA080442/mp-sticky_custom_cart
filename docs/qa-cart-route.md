# QA: редирект URL страницы корзины (WooCommerce)

Функция включается в **Настройки → Корзина → Маршрут страницы корзины WooCommerce** (`cart_route.redirect_to_home`).

## Поведение

- При включении запросы к странице корзины (`is_cart()` / `/cart/`, локализованный slug и т.д.) отвечают **редиректом** на главную сайта (`home_url( '/' )`), если не сработали защиты ниже.
- Код ответа задаётся полем **HTTP-код редиректа** (301, 302, 303, 307). По умолчанию в настройках **302** (временный).
- Обработчик: **`template_redirect`** с приоритетом **0** (ранний перехват).

## Защита от цикла

- Если страница корзины WooCommerce совпадает с **главной страницей** (статическая главная = страница корзины), редирект **не выполняется** (лог: `skip cart page is front page`).
- Если целевой URL после фильтра совпадает с URL корзины Woo, редирект **не выполняется** (лог: `skip target equals cart URL`).

## URL-варианты

WooCommerce сам нормализует запрос: и `/cart`, и `/cart/` попадают в `is_cart()` при корректных постоянных ссылках — отдельная настройка не требуется.

## Гости и авторизованные

Редирект не зависит от роли пользователя; одинаков для гостя и залогиненного.

## Логирование

Включите **«Писать события редиректа в debug.log»** при включённом `WP_DEBUG_LOG` (или смотрите сырой `error_log` на хостинге). Строки с префиксом `[mp-sticky-custom-cart] cart_redirect`.

Фильтр: `mp_sticky_custom_cart_should_log_cart_redirect`.

## Риски

- Ссылки с параметрами удаления позиции с корзины (`?remove_item=…`) перестанут открывать страницу корзины — при включённом редиректе учитывайте это в теме.
- Целевой URL можно изменить фильтром **`mp_sticky_custom_cart_cart_redirect_url`**.
- Отменить редирект в коде: **`mp_sticky_custom_cart_cart_redirect_short_circuit`** → `false`.

Внешние ссылки с `add-to-cart` и UTM: **`docs/qa-external-cart-links.md`**.
