# QA: вариативные товары (выбор вариации)

Ручные проверки для страницы товара и quick view с формой `form.variations_form`.

## Базовые

1. **Без выбранных атрибутов**  
   На вариативном товаре не выбирать цвет/размер и нажать «В корзину». Запрос добавления не должен уходить (сеть: нет успешного `admin-ajax` add-to-cart от этой формы). В sticky показывается текст из настроек «Выберите вариацию товара» (ключ `variation_required`). Блок атрибутов (`.variations` или вся форма, если таблицы нет) получает визуальный акцент (outline).

2. **После выбора вариации**  
   Выбрать допустимую комбинацию, дождаться появления цены/«В корзину» активной. Нажать добавить — товар в корзине, sticky обновляет счётчик и сумму, при успехе — сообщение «Товар добавлен в корзину» (если включено), **без** сообщения об ошибке вариации.

3. **Сброс подсветки**  
   После ошибки (п.1) изменить любой атрибут или сбросить вариацию (если тема даёт сброс) — класс акцента снимается, повторный клик без выбора снова показывает ошибку.

## Админка

4. **Текст ошибки**  
   В настройках плагина изменить строку «Сообщение «Выберите вариацию товара»», сохранить. На витрине при п.1 показывается новый текст в sticky.

## Регрессии

5. **Простой товар**  
   На simple-товаре добавление работает как раньше, без блокировки по вариации.

6. **Ложное обновление sticky**  
   При заблокированном добавлении (п.1) счётчик корзины в sticky **не** должен увеличиваться и не должно быть success-тоста добавления.

7. **Quick view**  
   Если в модалке есть `form.variations_form`, поведение как на странице товара (блокировка без вариации, тот же текст из настроек).

## Совместимость с темой

8. Темы с радиокнопками/свотчами вместо `<select>`: после выбора значения `variation_id` становится > 0 — добавление разрешено. Темы с кастомной разметкой без `.variations`: акцент применяется к `form.variations_form` целиком.
