# QA: постоянная видимость sticky-корзины

Чек-лист для ручной проверки поведения нижней панели (`#mp-scc-sticky-root`).

Регрессия по шаблонам (архив, single, блог, checkout, аккаунт и др.): **`docs/qa-sticky-everywhere.md`**, тест `node tests/sticky-everywhere.test.js`.

## 1. Пустая корзина

- [ ] Панель **отображается** при нуле позиций (счётчик `0`, сабтотал `0`).
- [ ] На корне есть `data-mp-scc-cart-empty="1"` и класс `mp-scc-sticky--empty` (после AJAX обновляется через `frontend.js`).
- [ ] Кнопка оформления заказа в состоянии **disabled** (см. отдельный сценарий checkout).

## 2. Шаблоны сайта

Проверить при включённом WooCommerce и активной sticky-панели:

- [ ] Главная (`is_front_page`).
- [ ] Архив магазина / каталог (`is_shop`, категории).
- [ ] Карточка товара (`is_product`).
- [ ] Корзина WooCommerce (`is_cart`).
- [ ] Оформление (`is_checkout`) — при необходимости скрыть панель фильтром `mp_sticky_custom_cart_should_render_sticky` (дублирование UI).
- [ ] Служебные страницы (контакты, политика и т.д.).

Условие вывода единое: `StickyCartVisibility::should_render_sticky()` (без проверки `is_empty()`).

## 3. CLS и первый рендер

- [ ] У `body` при активной панели есть класс **`mp-scc-sticky-active`**.
- [ ] Внизу страницы есть **зарезервированный отступ** `padding-bottom` (переменная `--mp-scc-sticky-layout-reserve` из настроек), чтобы контент не прятался под фиксированной полосой при скролле к футеру.
- [ ] При загрузке шрифтов панель не «прыгает» критично (при необходимости задать стабильные размеры кнопок в теме).

## 4. Длинная страница и футер

- [ ] Прокрутить к самому низу: последние строки контента **читаемы**, не перекрыты баром (за счёт `body.mp-scc-sticky-active`).

## 5. Модальные окна темы

- [ ] Открыть типичное модальное окно (заявка, быстрый просмотр и т.д.).
- [ ] Если панель перекрывает диалог, на время показа модалки добавить на `body` класс **`mp-scc-sticky-suppress`** (скрывает бар) или опереться на правило для `body.modal-open`, если тема добавляет этот класс.
- [ ] При необходимости скорректировать z-index модалки в теме (панель по умолчанию очень высокая).

## 6. Конфликт overflow / fixed

Если полоса «отрывается» от низа экрана или обрезается:

- [ ] Убедиться, что бар выводится в **`wp_footer`** (как сейчас), а не внутри блока с `transform` / `filter` (иначе `position: fixed` привязывается к предку).
- [ ] Проверить у обёрток темы `overflow: hidden` — при необходимости ослабить для контейнера, в котором лежит контент, **не** ломая весь сайт (индивидуально для темы).

## 7. Safe area, iPhone, landscape

- [ ] Портрет: нижний отступ учитывает **home indicator** (`env(safe-area-inset-bottom)` уже в CSS панели и в `padding-bottom` у `body`).
- [ ] Альбомная ориентация: боковые **вырезы** — в медиазапросе `(orientation: landscape) and (max-height: 500px)` усилены горизонтальные отступы панели и доп. запас у `body`.

## 8. Быстрые технические проверки

- [ ] `document.body.classList.contains('mp-scc-sticky-active')` на странице магазина — `true`.
- [ ] В `:root` или инлайн-стиле runtime есть **`--mp-scc-sticky-layout-reserve`**.
