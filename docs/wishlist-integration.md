# Wishlist + каталог: ограничения интеграции

Плагин **не вставляет** свою иконку избранного и **не дублирует** разметку сторонних плагинов. Интеграция сводится к:

1. **Слоистость (z-index)** — кнопка «Подробнее» (`--mp-scc-catalog-overlay-z-index`, по умолчанию 4) остаётся **ниже** типичных контейнеров wishlist (`--mp-scc-wishlist-icon-z-index`, по умолчанию 6), если включён флаг **«Интеграция heart-иконки»** и на `body` добавлен класс `mp-scc-wishlist-integration-on` (делает storefront JS).

2. **Зона клика** — горизонтальный зазор между полосой «Подробнее» и правым краем задаётся отступами сердечка и полем «Зазор overlay от сердечка» (`--mp-scc-wishlist-overlay-clearance` и связанные переменные в `assets/css/frontend.css`).

3. **Визуальные состояния (YITH)** — для YITH WooCommerce Wishlist при включённой интеграции дополнительно задаются **постоянные** цвета круга и иконки в каталоге: «не в избранном» и «в избранном» (вкладка **Избранное** в настройках плагина). В CSS используются переменные `--mp-scc-wishlist-heart-bg` / `--mp-scc-wishlist-heart-color` и `--mp-scc-wishlist-heart-in-list-bg` / `--mp-scc-wishlist-heart-in-list-color`. На корне карточки (`li.product` / `div.product` по селектору каталога) выставляется атрибут `data-mp-scc-wishlist="in"` или `"out"` по классу `.exists` у блока YITH и обновляется после событий `added_to_wishlist`, `removed_from_wishlist`, `yith_wcwl_fragments_replaced` и после AJAX-удаления.

4. **Второй клик по «перейти в wishlist» (YITH)** — если ссылка в карточке уже в состоянии «в списке» (типичная разметка: контейнер `.yith-wcwl-add-to-wishlist.exists` и ссылка без класса `.add_to_wishlist` с `href`, содержащим `wishlist`), клик **не ведёт** на страницу wishlist: выполняется серверный AJAX `mp_scc_yith_remove_from_wishlist` (удаление строк из таблицы `yith_wcwl_items` для текущего пользователя и товара), затем фрагмент кнопки при необходимости подменяется ответом сервера. Логика **рассчитана на YITH WCWL (в т.ч. Premium)**; при сильно кастомной разметке темы селекторы могут потребовать доработки в дочерней теме. Удаление **не привязано** к конкретному wishlist-id: снимаются все записи товара для пользователя в таблице YITH (как типичный сценарий «один список»).

5. **Тосты** — при успешном добавлении и удалении из избранного в каталоге показываются короткие сообщения на карточке (тот же механизм, что и для других каталожных уведомлений). Тексты настраиваются в разделе подписей на вкладке **Избранное** (или через стандартные переводы строк).

6. **Фокус с клавиатуры** — для ссылки «Подробнее» добавлен видимый `outline` при `:focus-visible`. Порядок табуляции определяется темой и порядком узлов в DOM; плагин не меняет `tabindex` у сторонних кнопок.

7. **Дубликаты в карточке** — если в одной `li.product` оказывается несколько кнопок wishlist, это ошибка темы/плагина. Для диагностики откройте каталог с `?mp_scc_wishlist_debug=1` в URL и смотрите предупреждения в консоли.

8. **Расширение селекторов** — при нестандартном плагине добавьте в дочернюю тему узкие правила `z-index` для своего селектора или используйте фильтр WordPress для данных storefront (при необходимости — отдельный мини-патч в теме).

9. **Гости** — поведение редиректа на логин для неавторизованных пользователей YITH плагин **не меняет**; перехват второго клика и AJAX-удаление актуальны для залогиненного пользователя.

Рекомендуется: **z-index избранного > z-index overlay** (настраивается в админке: Каталог → Z-index слоя «Подробнее», Избранное → Z-index иконки).
